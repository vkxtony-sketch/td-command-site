# TD Command website

Static homepage and privacy policy for the Google OAuth consent screen.

## Publish with GitHub Pages

1. Create a new public repository named `td-command-site` at <https://github.com/new> (no README, no .gitignore).
2. Upload the contents of this folder to the repository root, or push it with git.
3. In the repository, open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Wait about a minute, then open:
   - Homepage: `https://vkxtony-sketch.github.io/td-command-site/`
   - Privacy: `https://vkxtony-sketch.github.io/td-command-site/privacy.html`

## Use in Google Cloud Console

On the OAuth consent screen:

- **Application home page:** `https://vkxtony-sketch.github.io/td-command-site/`
- **Application privacy policy link:** `https://vkxtony-sketch.github.io/td-command-site/privacy.html`
- **Authorized domain (if requested):** `vkxtony-sketch.github.io`

## Before publishing

- The contact email in both pages is `vkxtony@gmail.com`. Change it if you want a dedicated support address.
- Review the privacy policy with a parent or guardian if you are a minor, and update it when you add tournament or player data features.
